# postcard-archive-policy

Public privacy policy for **Postcard Archive** (iOS / iPadOS / macOS / Android).

Published at: **https://rizkcorsight.github.io/postcard-archive-policy/**

The hosted page is what the App Store Connect and Google Play Console listings link to. To update the policy, edit `index.md` and push to `main`.

Contact: `rizkcorsight@rizkcorsight.com`
